# REQ-20261107-07：人类机械科技界面与战列舰菜单

用户通过浏览器标注明确：菜单背景使用深空与人类战列舰；整体采用星际争霸式画面风格；顶部HUD也统一为人类机械科技风。

本轮由Codex沿用现有文件所有权实现。菜单使用原创生成的深空战列舰插画，呈现厚重装甲、锤头舰艏、发动机与工业细节，替代核心示意图；地图仍为工业甲板。

界面采用枪灰装甲、金属倒角、铆钉、分隔槽、通风栅与低亮度仪表灯；替换原来的亮青/紫色圆角面板风格。HUD保持既有信息、按钮与命中区域。菜单标题为“星际塔防”，第四兵种为人族战列巡航舰，舰载激光炮不含拦截机。

维持16:9逻辑画面、2x渲染、制造/部署/升级/暂停/横向平移等现有操作。验收：菜单与浏览器标题正确、深空战列舰可见且不妨碍文字、上下控制台风格统一、四兵种和fallback可运行，typecheck/test/build与浏览器基础检查通过。

补充：终点采用星际人类指挥中心建筑，本地包缺失时用工业建筑回退。加入原创合成的太空军事氛围背景音乐，循环播放，首次用户交互后启动；提供独立音乐开关并持久化，跟随总音量/静音。菜单与暂停设置可调整，页面不可见时暂停音乐。

## 结果

已实现并完成基础浏览器验收：菜单标题/插画、四兵种制造部署、步态暂停、上下机械风、人族基地、本地包回退、音乐首次启动/循环/静音/零音量/持久化开关。33项测试及构建通过；未重新验收完整战役数值平衡。

后续动态菜单与独立音量已由需求11与13补充：音乐现跟随musicVolume，旧volume仅控制音效与单位语音，两路共同受总静音控制。
