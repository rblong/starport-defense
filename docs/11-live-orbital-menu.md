# REQ-20261107-09：动态地球、原版轮廓战列舰与菜单声效

## 目标

用户反馈首页是静态图片，地球应有光照变化；舰船造型应更贴近真实星际人族战列巡航舰，舰体和引擎喷焰应运动。补充要求修改“星际塔防”文字配色并为按钮配音效。

## 规则与范围

- 继续使用Phaser二维渲染，把菜单拆成独立星空、动态地球、透明舰体、喷焰与界面层，取消静态合成大图。
- 地球采用球面纹理投影和日夜光照、大气散射光晕及独立云层；纹理更新频率约12fps，主交互仍60fps。
- 舰体参考本地原版BattleCruiser轮廓制作高细节透明渲染；采用轻微航行位移、起伏及独立喷焰扰动。
- 本地原版图片仍仅作忽略目录内参考，生成的独立舰体保存项目资源。缺资源时保留程序化回退。
- 标题改为冷银/灰蓝金属字、暖金细节，不再沿用原米白色大字。
- 按钮悬停/确认/禁用反馈使用项目合成音，跟随音效/音量；首次点击解除浏览器音频限制，不自动播放未授权声音。
- 歌利亚、战列巡航舰选中语音回退链：本地专属音效→本地Marine选中→专属WAV→Marine选中WAV→合成无线电音。按钮范围包括模式/设置/暂停/结算、制造卡、部署栏和小地图。缺失文件与播放失败都处理，异步失败不得绕过静音。
- 减少动态时冻结地球/舰体位移并保留静态喷口光，不影响按钮。返回菜单不重复创建声音或动画更新器。

## 验收

验证地球画面随时间变化、舰体运动且轮廓可识别、喷焰独立变化；减少动态停止运动，按钮悬停与点击只播放一次且静音有效；标题、音乐及开始游戏操作正常；类型检查、单测、构建与浏览器检查通过。
