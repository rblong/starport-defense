# REQ-20261107-11：背景音乐听不到

目标：修复音乐过轻、首次交互被浏览器拦截后不重试以及界面缺少播放状态的问题。

范围：主页与战斗共用循环音乐，保留音乐开关、音量和静音持久化；开启音乐时恢复非零音乐音量并解除总静音。浏览器要求真实点击或按键后播放，未解锁时显示提示，播放失败显示重试提示。初步修复提高音乐增益，后由追加的独立音乐音量需求取代：默认音乐音量50%，与音效音量无关。不绕过浏览器自动播放规则。

验收：真实点击后音乐已解码且currentTime持续增长；关闭、静音、零音量停止，恢复后继续，切换场景不重头播放；失败后下一次交互可重试；加载失败有可见状态。

## REQ-20261107-12：音效与音乐分别调音量

用户追加：音效和背景音乐两个音量都可以分别设置。

首页和暂停菜单均提供音效音量、音乐音量两个独立按钮，按100/75/50/25/0%循环，默认各50%；分别保存。旧volume字段继续表示音效，新增musicVolume默认50%，兼容旧存档。音效归零不暂停音乐；音乐归零不影响音效/单位语音。总静音控制两路，音乐开关仅控制音乐。开启音乐只恢复音乐自身的非零音量，不改动音效音量。验收独立音量、刷新持久化、静音恢复与场景切换。
