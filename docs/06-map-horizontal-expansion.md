# 需求：地图横向扩展与拖动视角（v1）

需求编号：`REQ-20261107-02`
日期：2026-11-07
状态：已实现，浏览器已验证
关联玩法需求：[`docs/04-unit-gameplay-redesign.md`](04-unit-gameplay-redesign.md)

## 1. 目标

将当前单屏地图扩展为**约 2 倍横向长度**，并允许玩家左右拖动查看战场。

- 当前逻辑视口：1280×720。
- 新世界宽度：**2560**（2×1280）。
- 地图网格：**36 列 × 8 行**，单格 64px。
- 相机水平平移范围：世界 x=0 到 x=1280（视口显示宽 1280）。
- 垂直方向不拖动，保持一整屏高度。

## 2. 范围

### 包含

- 横向 2 倍长度地图、路径、部署点与指挥中心位置重排。
- 世界背景（星空/星云/暗角）覆盖完整 2560 宽度。
- 相机水平拖动、边界限制、初始视角与视角提示。
- 键鼠与触屏部署在新地图/平移相机下的坐标换算。
- 顶部 HUD 下方增加极简的横向视角指示条。
- 帮助/README/验收记录更新。

### 不包含

- 纵向滚动/缩放地图。
- 多关卡、关卡选择、Tiled/LDtk 编辑器接入。
- 小地图；本轮只做极简视角指示条。
- 新增敌兵/波次；现有 12 波与无尽模式继续复用。
- 单位受击/生命值机制。

## 3. 地图布局

- 世界宽 2560，高 720；网格 36×8，tile 64。
- 网格原点：`x=128`（左右各留 128px 边缘），`y=88`（HUD 64px + 24px 留白）。
- 路径（拐点，从左到右再折返）：

```text
(-3,3) → (8,3) → (8,6) → (17,6) → (17,1) → (26,1) → (26,4) → (35,4)
```

- 指挥中心：`(35,4)`，位于地图最右侧。
- 部署点：32 个，覆盖左、中、右三个交战区；不得与路径线段冲突。
- 初始相机视角：世界左侧（viewX=0），先看到入口和左侧部署区；指挥中心在右侧，需拖动查看。
- 路径总长度增加，敌人从入口到指挥中心的行程变长；第一波平衡需要在实现后重新验证。

## 4. 相机与交互

### 4.1 拖动地图

- 在战场空白处按住左键左右拖动 = 平移相机。
- 拖动阈值约 6px；未超过阈值视为点击，仍然选择单位。
- 拖动不触发单位选择、部署或技能。
- 处于“待部署/点击部署”或“轨道轰炸瞄准”模式时，不在战场拖动平移；先取消当前操作再拖动。

### 4.2 键盘

- `A` / `←`：向左平移 160px。
- `D` / `→`：向右平移 160px。
- 平移在 [0, 1280] 范围内 clamp，不露黑边。

### 4.3 视角提示

- HUD 下方显示一条横向视角条：
  - 轨道代表 2560 世界宽度；
  - 高亮块代表当前 1280 视口；
  - 随相机移动实时更新。
- 进入战斗时显示一次提示：“按住战场左右拖动查看地图，A/D 也可平移”。

### 4.4 部署坐标

- 从底部待部署区拖到战场时，UIScene 只上报画布指针坐标；
- GameScene 用**当前平移相机**换算为世界坐标，再寻找部署点。
- 避免 UIScene 固定相机与 GameScene 平移相机坐标不一致造成部署偏移。

## 5. UI / 场景约束

- HUD、制造栏、暂停/结算弹窗、帮助界面固定在屏幕上，不随相机移动。
- 底部制造/待部署 UI 保持不变；不因地图变宽而移动。
- 下一波预览、波次横幅、Boss 血条继续固定屏幕。
- 背景的横向暗角在世界边缘，而不是视口边缘。

## 7. 影响与风险

- 路径变长会改变敌人到达时间与波次节奏，需要重新做第 1 波与 Boss 波的基础试玩。
- 相机平移后，所有依赖鼠标坐标的逻辑必须使用 GameScene 相机换算；UIScene 拖放必须改传画布坐标。
- Phaser 输入、2x 渲染缩放与水平拖动叠加时需用真实浏览器验证。
- 旧测试中断言 18 列/16 个部署点、`isOnPath` 只比较拐点，需要同步更新，并补充路径线段冲突校验。
